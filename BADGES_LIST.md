### How to add to README

Copy the code block below and paste it into the `Completed Cadet Projects` section of your `README.md`.
Replace `YOUR_GITHUB_USERNAME` with your actual username (e.g., `claudio1code`).

```html
<!-- Project Name -->
<a href="https://github.com/YOUR_GITHUB_USERNAME?tab=repositories&q=project_name" target="_blank">
  <img src="IMAGE_URL_FROM_BELOW" alt="Project Name" width="150" height="150" />
</a>
```
